## Адаптация

Пути/crates/owner keys адаптированы под Vecta, AGPL provenance сохранён.
Трёхстороннее совмещение использовало нормализованные upstream base/new и actual Vecta;
конфликты разобраны вручную. Generated Rust вручную не правился.
Сохранены наши ItemFrame/GlowItemFrame, entity pick, UUID/command contexts, loot RNG,
меню/containers, server fields и последовательный world dispatch.

В `World::default_block_drops` explosion radius добавлен внутрь нашего `with_loot`
consumer: upstream случайный RNG не заменил общий seeded loot foundation.

Дополнительно исправлено:

- GlowItemFrame делегирует ignore_explosion обычной рамке. Upstream этой полноценной
  сущности не имел; перенос только ItemFrame hook оставлял бы наш subtype без защиты.
  Explosion tests расширены на оба вида рамок и проверяют сохранность сущностей.
- TNT prime сохраняет success/sound/event при rejected insertion, как Java TntBlock.prime,
  которая игнорирует addFreshEntity boolean. Upstream возвращал false; добавлен
  regression на unloaded target chunk.

Первый type-check выявил test-only has_chunk вместо has_full_chunk и лишний импорт
после merge; исправлено. Runtime failures этим не скрывались.
Первый workspace compile также выявил оставшееся `Identifier::from_steel` в новом
packet test; адаптировано к существующему `from_vecta`, отдельный packet filter прошёл.

  требуют настоящих consumers; TNT engine не закрывает все типы взрывов.
