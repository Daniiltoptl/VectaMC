## Как переносилось

Upstream-история переименована скриптом (пути `steel-*` → `vecta-*`,
идентификаторы `steel`/`Steel`/`STEEL` → `vecta`, кроме `flint_and_steel`,
`SteelExtractor`, ссылок на SteelMC и Flint), затем каждый commit перенесён
`cherry-pick -x` с ручным разбором конфликтов. Commit-сообщения содержат
`Upstream-commit: Steel-Foundation/SteelMC@<sha>`.

## Известные вопросы

- Позиции появления у спавнера upstream берёт из `rand` (unseeded). Java берёт
  `level.getRandom()`; по AGENTS это допустимая живая случайность, но поток
  level random не продвигается так, как в Java.
- Стол зачарования и награда ITEM_CRAFTED за печь — на агента A.
- Ванильность upstream-кода построчно с Java не сверялась целиком: проверены
  только места конфликтов и спавнер.
