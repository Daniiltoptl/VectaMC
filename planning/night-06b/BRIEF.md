# Агент B, сеанс 12: параллельный поток (пакет 06, облако)

Ты второй исполнитель и работаешь в облачной копии репозитория (Linux).
Параллельно агент A работает локально в ветке `codex/night-vanilla-03`.
Чтобы не мешать друг другу, у тебя своя ветка и свои области работы.

## Проект за минуту

VectaMC — сервер Minecraft Java 26.3 на Rust. Цель — поведение 1:1 с ванилью.
Java-исходники — единственный источник истины. Правила кода — `AGENTS.md`, они
важнее общих привычек. Работу проверяет Claude, ревью лежат в `planning/reviews/`.

## Рабочее место

- Ветка: `codex/night-vanilla-03-b`. Сделай `git fetch origin` и
  `git checkout codex/night-vanilla-03-b`. Пушь только её. В
  `codex/night-vanilla-03` и main не пушь, не мержи, не ребейзь, не force-push.
- Журнал свой: `planning/night-06b/` (progress.md, checkpoint.md, blockers.md,
  report.md). Общие `planning/night-06/*` и `CHANGELOG.md` не трогай: их правит
  агент A.

## Java-исходники (первый шаг)

`minecraft-src/` в .gitignore, в облаке его нет. Сгенерируй его штатным
скриптом: `./update-minecraft-src.sh` (вызывает `scripts/prepare_vanilla.py`;
версия берётся из `Cargo.toml`, суффикс `+mc...`). Не принимай EULA и не
запускай ванильный сервер. Если скрипт не может скачать или декомпилировать
(нет сети, нет Java), запиши точную ошибку в `planning/night-06b/blockers.md`,
закоммить, запушь и остановись с отчётом: без Java-источников игровой код
писать нельзя.

SteelExtractor в облаке нет. Если для пункта нужны данные, которых нет в
`*/build_assets/` или `*/test_assets/`, это блокер: опиши, какой файл нужен, и
бери следующий пункт. Руками registry/protocol данные не вписывать.

## Сборка

Nightly Rust (`rust-toolchain` в репо). Перед каждым коммитом кода:

```
cargo fmt --all --check
cargo test --locked --workspace
cargo clippy --locked --workspace --all-targets --all-features -- -D warnings
```

После: `python scripts/audit_vanilla.py`, `python -m unittest discover -s scripts`.
Последний итог workspace: 4402 passed / 0 failed / 18 ignored. При OOM добавь
`-j 1`; если и так падает — блокер.

## Начало

останавливайся после одного пункта.

## Твои области (только они)

Агент A работает над крафтом, оружием, выживанием, мобами, зачарованиями,
предметами, сущностями, игроком, сохранением. Их не трогай. Если нужен его
фундамент — блокер «нужно от агента A», иди дальше. Старайся не менять общие
трейты (`BlockBehavior`, `Container`, `Entity`) без крайней нужды; если
меняешь — минимально и с пометкой в отчёте.

### 1. Редстоун (G101–G104)

- Пыль: power graph, соединения, порядок обновлений по Java
  `RedStoneWireBlock` и `RedstoneWireEvaluator` (учти experimental/default).
- Повторители, компараторы (режимы, чтение контейнеров через
  `getAnalogOutputSignal`), факелы (burnout).
- Поршни: push limit 12, slime/honey, неподвижные блоки, блоки с блок-сущностью,
  `MovingPistonBlock`, порядок тиков.
- Рельсы: питание, активаторные, детекторные.

### 2. Жидкости, огонь, растительность (G105–G107, G116, G117)

- Жидкости: растекание, источники, lava+water (камень, булыжник, обсидиан,
  базальт), вёдра, waterlogging, скорость в Аду.
- Огонь: распространение, burn odds по данным, дождь, soul fire, костры,
  свечи.
- Рост растений по `randomTick`: саженцы и TreeGrower из реальных configured
  features, костная мука для всех блоков, тростник, кактус, бамбук, лозы,
  пещерные лозы, big dripleaf, ягоды, нарост, хорус, тыквы/арбузы, какао,
  грибы, кораллы, келп, аметист, сталактиты (падение, капли), лёд/снег по
  свету, порошковый снег.
- Погода и молния (громоотвод, превращения мобов не трогай — это агент A).

### 3. Интерактивные блоки

Котлы (все виды, капельник), проигрыватель, нотный блок, колокол, рычаги,
кнопки, нажимные плиты, растяжка, наблюдатель, датчик дневного света, мишень,
громоотвод, sculk sensor (частоты) и калибровочный, окисление меди и воск,
медные лампы, строительные леса, черепашьи и снюхачьи яйца, сундуки (двойные,
ловушка, эндер), бочки, шалкер-боксы, резные книжные полки.

### 4. Измерения и порталы (G095, G119)

Адский портал (рамка любого размера, поиск/создание через POI, масштаб 8,
cooldown, сущности), портал Энда, end gateway, граница мира, void,
`dimension_type`-правила.

### 5. Команды

Проверь, какие есть, доделай по Java: `fill`, `fillbiome`, `clone`,
`setblock`, `place`, `locate`, `spreadplayers`, `forceload`, `worldborder`,
`weather`, `time`, `difficulty`, `gamerule`, `setworldspawn`, `spawnpoint`,
`particle`, `playsound`, `stopsound`, `tick`, `scoreboard`, `team`, `bossbar`,
`title`, `tellraw`, `schedule`, `execute` (все подкоманды). Дерево аргументов,
права, ванильные translation keys.

### 6. Покрытие протокола

`planning/audit/protocol-coverage.md`: таблица всех пакетов 26.3 из extracted
данных — реализован / есть обработчик / нет. Закрывай пробелы своих областей.

### 7. Worldgen (H1), если всё выше упёрлось в блокеры

RNG.
