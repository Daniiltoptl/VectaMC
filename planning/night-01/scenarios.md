# Ночной сеанс 01 — игровые сценарии

Сценарии, которыми проверяются задачи. Формат: условия → действия → ожидание
по vanilla → фактический результат в VectaMC → чем подтверждено.

Отдельно фиксируется, чем именно подтверждён результат: чтение кода,
unit-тест, тест через существующий тестовый connection или наблюдение
настоящим клиентом. Одно не заменяет другое.

## Дополнение Codex: выполненные проверки N02

Ожидания взяты из локальных исходников 26.3; все строки ниже подтверждены
in-process тестами, без настоящего клиента и без запуска Minecraft-сервера.

| Условия и действие | Ожидание vanilla | Результат Vecta после исправлений |
| --- | --- | --- |
| Правый клик одного мешка по другому с выбранным содержимым | После отказа cursor override вызывается slot override, выбор сбрасывается | Совпадает |
| Selection packet для другого предмета с `BUNDLE_CONTENTS` | Изменяется выбор компонента; повтор индекса снимает выбор | Совпадает через player handler |
| Использование main/offhand в survival/creative | Направленный drop, thrower, pickup delay, drop/use stats, расход содержимого | Совпадает для всех четырёх сочетаний |
| Выбор второго stack и использование до 12-го тика | Сначала выбранный stack; следующий на remaining=188 | Совпадает |
| Уничтожение item entity заполненного мешка | Компонент очищен, содержимое выпадает на позиции, без player-drop attribution | Совпадает |
| Default mutable → вставка → выбор 0 | Первый выбор устанавливается, а не отменяется | Совпадает |
| Разные custom stack sizes 97/89/83/79, затем 73 | Commons Fraction overflow; click не доходит до client prediction updates | Совпадает; следующий допустимый пакет обрабатывается |
| Общий вес больше 1 при допустимых отдельных stack | Новая вставка не проходит, извлечение работает | Совпадает |
| Runtime-компонент не проходит persistent codec | Runtime snapshot сохраняет предмет; codec-ошибка остаётся на границе сохранения | Совпадает |
| Невалидные runtime templates при use tick | Ошибка entity tick вместо молчаливой очистки | Проверено ожидаемое исключение теста |
